# Greenwood kitchen notes: cooked rice

This is original fictional household workflow content for a software demonstration, not authoritative food-safety guidance.

## Storage workflow

When the Greenwood household stores cooked rice, its demo checklist says: use a clean covered container, add a preparation-date label, and place it in the refrigerator. Review current official local food-safety guidance for actual cooling, storage-duration, temperature and reheating requirements. Those limits are deliberately not supplied by this fictional document.

## Planning workflow

The family reviews labels before choosing leftovers. A dated container helps the planner discuss what should be checked first. A citation explains the source of this household note; it does not establish medical or food-safety authority. Pantry quantities and nutrition are calculated separately by deterministic application services.
